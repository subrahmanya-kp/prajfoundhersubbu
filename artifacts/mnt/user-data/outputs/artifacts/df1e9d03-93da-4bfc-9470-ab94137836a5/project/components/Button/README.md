# Button

The invite's few actions: view events, open the map. **Primary** (kumkum) at most once per section; **secondary** is a kumkum outline. On maroon use **gold** (primary) and **outline-light**; kumkum has no contrast on maroon.

Props: `variant` (`primary` | `secondary` | `gold` | `outline-light`), `size` (`md` | `lg`), `icon`, `href` (renders a link), plus any button attribute. Labels are short and verb-first.
