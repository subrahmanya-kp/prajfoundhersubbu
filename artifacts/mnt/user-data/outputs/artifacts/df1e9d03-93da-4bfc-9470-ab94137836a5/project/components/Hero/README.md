# Hero

The invitation itself: toran, invocation, the couple's names in a double temple-arch frame topped with a kalash, both event dates side by side, place and two actions.

Props: `bride`, `groom`, `invocation` (default "|| Sri Ganeshaya Namaha ||"; replace with the family's own, or pass `false`), `eyebrow`, `joiner` (default "weds"), `intro`, `events` (`[{label, date}]`, two), `place`, `primaryCta`, `secondaryCta`. Always maroon.
