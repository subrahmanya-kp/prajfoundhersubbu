# Logos

There is no fixed logo; each couple gets a **monogram**: their initials in the arched frame with a lamp flame.

- `monogram-template.svg`: gold frame and ink initials, for ivory grounds.
- `monogram-template-on-maroon.svg`: temple-gold frame and light initials, for maroon.

Edit the `<text>` for the couple's initials, or use the `Monogram` component. Bride's initial first, in Cormorant Garamond Italic 600.
