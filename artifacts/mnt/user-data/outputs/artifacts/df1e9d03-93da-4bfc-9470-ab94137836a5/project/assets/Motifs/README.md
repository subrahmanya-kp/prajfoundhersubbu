# Motifs

Static copies of the ornaments for printed or shared invites.

- `toran-jasmine.svg`: 768×96 garland of mango leaves (`leaf`) and jasmine strings (`jasmine`, outlined in `temple-gold`), drawn for maroon. Tile it horizontally.
- `lamp.svg`: kuthu vilakku, temple gold.
- `jasmine.svg`: jasmine flower, gold.
- `kalash.svg`: kumkum. Used for the Wedding.
- `lotus.svg`: gold.

Keep each motif in its colour.
